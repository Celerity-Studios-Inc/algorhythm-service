## 🚀 **Usage Guidelines**

### **📁 Adding New Files**
- **Documentation**: Place in appropriate `docs/` subfolder
- **Scripts**: Categorize and place in `scripts/` subfolder
- **Infrastructure**: Place in `infrastructure/` folder
- **Source code**: Always in `src/` folder

### **📁 File Naming**
- **Use descriptive names** that indicate purpose
- **Use consistent naming** conventions
- **Avoid generic names** like `temp` or `misc`
- **Include dates** for time-sensitive files

### **📁 Documentation**
- **Keep docs updated** with current status
- **Use clear headings** and structure
- **Include examples** where helpful
- **Link related documents**
