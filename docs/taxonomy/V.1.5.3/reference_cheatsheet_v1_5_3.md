## 📊 **API Endpoints Reference**

### **Base URL**: `https://registry.dev.reviz.dev/api/taxonomy`

### **Core Endpoints**
- `GET /layers` - Get all layer names
- `GET /layers/{layer}/categories` - Get categories for a layer
- `GET /layers/{layer}/categories/{category}/subcategories` - Get subcategories for a category
- `GET /version` - Get taxonomy version
- `GET /health` - Get taxonomy health status

### **Utility Endpoints**
- `GET /layers/{layer}/subcategory-counts` - Get subcategory counts for a layer
- `GET /layers/{layer}/categories/{category}/subcategory-count` - Get subcategory count for a category
- `GET /layers/{layer}/category-count` - Get category count for a layer
- `GET /layer-count` - Get total layer count
- `GET /index` - Get taxonomy index
- `GET /tree` - Get complete taxonomy tree
