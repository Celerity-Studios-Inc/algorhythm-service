  description: |
    Single-call API for complete video remixing experience with GCP URL-based architecture.
    
    **Key Features:**
    - ✅ Complete experience in one API call
    - ✅ GCP URLs for all media assets (not embedded data)
    - ✅ 95% smaller responses (5MB vs 100MB)
    - ✅ Parallel CDN loading support
    - ✅ Mobile-optimized performance
    
    **Architecture:**
    - API returns asset metadata + GCP Storage URLs
    - Clients load actual assets from GCP CDN in parallel
    - Global edge caching for sub-50ms asset delivery

    post:
      tags:
        - ReViz Experience
      summary: Get complete ReViz experience
      description: |
        Returns everything needed for a complete video remixing experience in a single API call:
        - Song metadata with GCP URLs
        - 5-10 recommended composite videos with GCP URLs
        - Layer assets (Stars, Looks, Moves, Worlds) with GCP URLs
        - Base + variant assets (up to 149 assets)
        - Asset relationships and compatibility scores
        - Performance metrics
        
        **Response Size:** Typically 2-5MB (with GCP URLs)  
        **Response Time:** <200ms (cached), <500ms (uncached)
